# 검색어 확장 사전

이용자가 입력한 말에 이 표의 왼쪽 말이 있으면, 오른쪽 말을 검색어에 더해서 찾습니다.
조각 키워드에는 넣지 않습니다(조각 키워드는 조각에 실제로 나오는 말만 씁니다).
오른쪽 말은 모두 `docs/답변참고문서/청킹` 조각에 나오는 법령 용어입니다. 뜻이 꼭 같지 않은 짝(예: 압류 → 체납처분)은 넣지 않았습니다.

## 이번 검토에서 뺀 짝
| 뺀 짝 | 뺀 이유 |
| --- | --- |
| 압류 → 체납처분 | 압류는 체납처분의 한 부분이라 뜻이 같지 않음 |
| 추가 세금 → 가산세 | 뜻이 넓어 엉뚱한 조문을 끌어옴 |
| 지방 세금 → 지방세 | 거의 같은 말이라 넓혀 찾는 효과가 없음 |
| 납부 기한 연장 → 기한의 연장 | 기한의 연장은 신고 기한 등도 포함해 뜻이 더 넓음 |
| 관리사무소 → 관리주체 | 관리주체에는 관리업자 등도 포함되어 뜻이 같지 않음 |
| 쓰레기 부담금 → 폐기물부담금, 분리수거 → 분리배출 | 오른쪽 말이 지금 조각에 나오지 않음 |
