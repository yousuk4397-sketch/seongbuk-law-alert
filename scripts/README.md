# 데이터 만들기 스크립트

원본 법령·조례 파일에서 답변 근거 조각(`docs/답변참고문서/청킹`)을 만드는 순서입니다.
모두 Python 3 기본 기능만 씁니다(추가 설치 없음). 명령은 `team_project_05` 폴더에서 실행합니다.

| 순서 | 스크립트 | 하는 일 | 입력 → 출력 |
| --- | --- | --- | --- |
| 1 | `convert.py` | .hwp(국가법령정보센터 XML형)·.docx·.txt 를 .md 로 바꾼다 | `docs/작업자료/원본` → `docs/작업자료/청킹전` |
| 1-1 | `hwp5_convert.py` | 이진 HWP 5.0(첫 바이트 `D0 CF 11 E0`, 예: 조례 별표 첨부) 을 .md 로 바꾼다. 파일 하나씩 | `원본/별표/*.hwp` → `청킹전/별표/*.md` |
| 2 | `clean.py` | 머리말 표·쪽번호 꼬리말 표·겹친 빈 줄을 뺀다 | `청킹전` 안에서 고침 |
| 3 | `build_chunks.py` | 조마다(법령·조례) / `##` 마다(해설) 자르고, 메타데이터·맥락 줄을 붙인다. 삭제 조문 조각은 검색제외 폴더로 보낸다 | `청킹전` → `docs/답변참고문서/청킹`, `docs/작업자료/검색제외조각` |
| 4 | `kw_build.py` | 둘째 줄에 키워드를 넣는다(법령은 규칙으로, 조례·해설은 `data/키워드_수작업.json`) | `청킹` 안에서 고침 |

`build_chunks.py` 는 `chunk.py` 의 자르기 함수를, `kw_build.py` 는 `kw_law.py` 의 키워드 규칙을 가져다 쓴다.

## 실행 예
```
py -I scripts/convert.py docs/작업자료/원본 docs/작업자료/청킹전 보고서_변환.json
py -I scripts/clean.py docs/작업자료/청킹전 보고서_정제.json
py -I scripts/build_chunks.py docs/작업자료/청킹전 docs/답변참고문서/청킹 docs/작업자료/검색제외조각 scripts/data/원문링크.json 보고서_조각.json
py -I scripts/kw_build.py docs/답변참고문서/청킹 보고서_키워드.json --write
```
- 3번은 빈 출력 폴더에 실행한다(이미 있는 조각을 덮어쓰지 않도록).
- `kw_build.py --check` 는 들어 있는 키워드와 다시 만든 키워드가 같은지만 본다.

## 손으로 한 작업 (스크립트로 다시 생기지 않음)
- `청킹전/공동주택관리법/공동주택관리법 개정사례.md` 의 버전 표와 「법령 비교」 절 (2026-11-12 결정 1)
- 사례 문서 2개의 작성자 줄 삭제 (결정 7)
- 조례·해설 조각 키워드 (`data/키워드_수작업.json`)
- 원문 링크 (`data/원문링크.json`, 국가법령정보센터에서 판별로 열리는 것을 확인함)
- 별표 조각 키워드(`data/키워드_수작업.json` 에 함께 들어 있음). 별표는 `build_chunks.py ... _별표` 처럼 마지막 인자로 별표만 만들 수 있다

원본을 다시 변환하면(1번) 위 손작업이 사라지므로, 1번은 새 원본을 더할 때만 그 파일에 대해 실행한다.
